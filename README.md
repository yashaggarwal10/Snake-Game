# Classic Snake-Game

A web-based implementation of the classic Snake Game built using **HTML**, **CSS**, and **vanilla JavaScript**. This project demonstrates core front-end development skills including DOM manipulation, event handling, and game loop mechanics.
---

## 🛠️ Features

- Responsive UI with clean and simple design
- Real-time score tracking
- Dynamic snake movement and food generation
- Game-over detection and restart logic
- Lightweight with no external libraries

---

## 📂 Tech Stack

- **HTML5** – Structure and layout  
- **CSS3** – Styling and responsive design  
- **JavaScript (ES6)** – Game logic and interactivity
